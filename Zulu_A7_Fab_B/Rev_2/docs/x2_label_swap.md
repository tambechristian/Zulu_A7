# X2 pin names in the number row; title, U1 and U4 labels lowered (2026-11-24)

Silkscreen only. Copper, mask, paste, drill, outline, stack-up, parts, BOM and placement are unchanged.
This is the same change as on no-PMOD Rev 3. The full reasoning, the clearance method and the X2 housing study
are in `Zulu_A7_no_pmod/Rev_3/docs/x2_label_swap.md`. This file records what differs on Fab B and this board's
facts.

Later the same day R4's label also moved (see "R4 label"); the final board is MD5 `0fafba3d`.

## Why and what

PCBWay's photos of the first Zulu A7 order showed the printed "U1" beside the flash U4 and the two parts nearly
touching. On that ordered board, U4's body overlaps U1's by 0.14 mm. On this board, U4 clears U1 by 0.26 mm: it
was moved 0.4 mm north on 2026-11-14.

The owner chose:

- **Silkscreen only.**
- **Names into the numbers' place:** each X2 name moves to the pin-number row and the numbers are removed, power
  and control names included.
- **Lowered labels:** the title, U1 and U4 labels move down into the freed row.

| Item | Before | After |
|---|---|---|
| X2 pin names | inner row (y 20.939 / 3.661) | number row next to the pins (y 22.189 / 2.411), x unchanged |
| X2 pin numbers (30 texts) | printed | removed |
| '2 CLK' / '30 C20' / '21 GND' (vertical) | | 'CLK' (letters in place), 'C20' and 'GND' in the numbers' place |
| Title 'ZULU A7 2.2' | y 5.00 | y 3.77 (down 1.23 mm); the text is unchanged |
| U1 label | designator at (39.70, 16.55), beside U4 | free text 'U1' at (45.867, 5.63) under the FPGA; designator hidden |
| U4 label | designator hidden | free text 'U4' at (52.60, 19.40), right of U4 |

- **Pin 21:** keeps a vertical 'GND' here. A horizontal one would come 0.117 mm from JP4-1's mask. Rev 3 has
  no JP4 there, so it uses a horizontal GND.
- **Unlabelled pins:** pins 1 and 4-9 still carry no label.
- **Title:** it stays 2.2, so this package and the 2026-11-20 one print the same revision text; only the artwork
  differs.

Tightest clearances are the same as on Rev 3:

- names to the X2 mask: 0.254 mm;
- adjacent names: 0.257 mm;
- title to the names: 0.324 mm;
- title to the 'U1' label: 0.385 mm;
- 'U4' label to U4's pads: 0.569 mm.

Edge clearances are unchanged: the closest are 'AI1' / '1V0' on the west edge, at 0.255 mm.

tolerance. Hold each strip toward the board edge while soldering. At the next layout spin, give those parts about
0.25-0.3 mm more clearance.
