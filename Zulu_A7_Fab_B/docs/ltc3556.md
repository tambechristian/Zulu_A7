# U8 bq24232 + U5/U6/U7 -> Analog Devices LTC3556 (2026-11-10)

User decision: one LTC3556 replaces the charger (U8 bq24232), the 3.3 V buck-boost (U5 TPS63802) and both SC189 bucks (U6, U7), and sequences the rails VCC1V0 -> VCC1V8 -> VCC3V3 (SEQ = GND, ENALL) with no supervisor IC. Same circuit on Zulu A7 Fab B and Asar Feather; only ENALL differs (Fab B: VU, always on; Asar: the Feather EN net, R26 pull-up).

Designed from the LTC3556 datasheet Rev A (3556fa, LCSC mirror; the ADI copy was unreachable, Rev B unchecked) by two independent designs and a judge that re-checked every pin and value against the datasheet. Sheet 1 edited by Asar_feather/tools/apply_ltc3556.py; every one of the 97 new pins checked against this table, all other nets unchanged; ERC 0 errors, no new warnings on both boards.

**Open (user):** R103 CLPROG value (3.01k placeholder = ~96 mA from USB in the I2C-off 1x mode; ~560-620 ohm planned for ~440-480 mA, needs ADI/bench confirmation); VCC1V0 load vs Buck1 400 mA (confirm with AMD XPE).

## Calculations

- Buck1 (p22, p5): VOUT1 = 0.8 x (1 + 100k/402k) = 0.8 x 1.2488 = 0.999 V. Servo 0.780-0.820 V gives 0.974-1.024 V, inside Artix-7 VCCINT 0.95-1.05 V. FB bias error = 50 nA x (100k||402k = 80.1k) = 4.0 mV. Divider current = 0.999/502k = 2.0 uA.
- Buck2 (p22, p6): VOUT2 = 0.8 x (1 + 150k/120k) = 0.8 x 2.25 = 1.800 V. Servo tolerance gives 1.755-1.845 V, inside VCCAUX/VCCADC 1.71-1.89 V. FB error = 50 nA x 66.7k = 3.3 mV.
- Buck-boost (p28, p30): VOUT3 = 0.8 x (1 + 324k/105k) = 0.8 x 4.0857 = 3.269 V. Servo tolerance gives 3.187-3.350 V, inside 3.135-3.465 V (VCCO +-5 %). 102k (3.341 V) would re-centre it without touching the AC loop.
- Type III (p29 transfer function, p30 values): integrator 1/(2*pi*R1*(C1+C2)) = 1/(2*pi*324k*340p) = 1.44 kHz. fz1 = 1/(2*pi*R2*C2) = 1/(2*pi*15k*330p) = 32.2 kHz. fz2 = 1/(2*pi*(R1+R3)*C3) = 1/(2*pi*445k*33p) = 10.8 kHz. fp1 = 1/(2*pi*R3*C3) = 1/(2*pi*121k*33p) = 39.9 kHz. fp2 = 1/(2*pi*R2*(C1*C2/(C1+C2))) = 1/(2*pi*15k*9.71p) = 1.09 MHz.
- LC double pole (p29): 1/(2*pi*sqrt(2.2u*22u)) = 22.9 kHz nominal; about 31 kHz with C80 derated to about 12 uF at 3.3 V; about 8-11 kHz if the distributed decoupling (about 100-167 uF) counts. Zeros at 10.8/32 kHz sit 'before or only slightly after' the pole, as p30 requires.
- Boost RHP zero (p29), worst case VIN3 = 3.0 V, IOUT = 0.662 A: fRHPZ = VIN^2/(2*pi*IOUT*L*VOUT) = 9/(2*pi*0.662*2.2e-6*3.3) = 298 kHz, well above crossover. Type I was rejected: it must cross a decade below the LC pole (about 1-2 kHz), and p29 says Type III gives the bandwidth and lower start-up overshoot.
- PROG (p18, p3): ICHG = 1022 V / 4.12k = 248 mA. Trickle (BAT < 2.85 V) = ITRKL = 0.1 x ICHG = 24.8 mA. C/10 end of charge = 24.8 mA. Maximum PROG parasitic for a 100 kHz pole: 1/(2*pi*100k*4.12k) = 386 pF (p34). IPROG = 1 V/4.12k = 0.24 mA < 2 mA abs max.
- CLPROG at 3.01k (p16, p3 1x: IVBUSQ 7 mA, hCLPROG 224): IVBUS = 7 mA + 1.188/3010 x 225 = 7 + 88.8 = 95.8 mA, matching IBUSLIM 1x 87/95/100 mA. VOUT current available is about 135 mA at BAT = 3.3 V (p3).
- CLPROG planned range: R = 1.188 x 225/(I - 7 mA). 500 mA -> 542 ohm; 450 mA -> 603 ohm. 560 ohm -> 7 + 477 = 484 mA; 590 ohm -> 460 mA; 604 ohm -> 450 mA; 620 ohm -> 438 mA. ICLPROG = 1.188/560 = 2.12 mA < 3 mA abs max, so RCLPROG_min = 1.188/3 mA = 396 ohm.
- CLPROG filter: 3.01k x 1 uF = 3.0 ms; 560 ohm x 1 uF = 0.56 ms. Both are slower than the datasheet's RC alternative, so the 0.47 uF minimum is met with margin after the -10 % tolerance and DC bias at 1.19 V.
- Power budget at VU about 3.7 V (efficiency about 80/85/90 %): typical 1.0 x 0.36/0.80 + 1.8 x 0.049/0.85 + 3.3 x 0.334/0.90 = 0.45 + 0.10 + 1.22 = 1.78 W (0.48 A). Maximum 0.46 + 0.16 + 2.43 = 3.05 W (0.82 A at 3.7 V, 1.0 A at a 3.0 V cell). USB at 480 mA x 5 V x 0.9 is about 2.2 W, so the typical load fits on USB only after the RCLPROG change; at 3.01k the battery carries almost everything.
- Ideal diode on battery only: 1.0 A x 0.18 ohm = 0.18 V drop, below IMAX_DIODE 1.6 A min (p4). VU is about 2.8 V at a 3.0 V cell, above the 2.6 V VOUT UVLO. So GATE no-fit is acceptable; margin is thin only at end of discharge.
- L8 PowerPath ripple (5 V -> 3.8 V, 2.25 MHz): dI = (5 - 3.8) x (3.8/5)/(2.25M x 3.3u) = 0.123 A p-p. Peak about 0.65 + 0.06 = 0.71 A, against Isat 2.5 A and the 2 A typ switch limit.
- L3 Buck1 ripple (4.5 V -> 1.0 V): dI = (4.5 - 1.0) x (1.0/4.5)/(2.25M x 2.2u) = 0.157 A p-p. Peak = 0.367 + 0.079 = 0.45 A < ILIM1 min 0.6 A. Rating checks: Itemp 2.3 A >= 1.5 x 0.4 = 0.6 A; Isat 3.3 A >= ILIM1 max 1.1 A.
- L2 Buck2 ripple (4.2 V -> 1.8 V): dI = (4.2 - 1.8) x (1.8/4.2)/(2.25M x 2.2u) = 0.208 A p-p (0.22 A at 4.5 V). Peak about 0.19 A at 77 mA. Itemp 1.7 A >= 0.6 A; Isat 1.9 A >= 1.1 A.
- L1 buck-boost: boost at VIN3 = 3.0 V, IIN = 3.3 x 0.662/(3.0 x 0.9) = 0.81 A plus about 0.1 A half-ripple. Itemp 2.3 A >= 2 x 0.662 = 1.32 A; Isat 3.3 A >= ILIMF3 max 3 A. In buck mode (4.2 -> 3.3 V): dI = (4.2 - 3.3) x (3.3/4.2)/(2.25M x 2.2u) = 0.143 A p-p.
- Buck1 load margin: 347-367 mA vs IOUT1 400 mA (p5) leaves 8-13 % headroom. The user will confirm with AMD XPE.
- LD3: (3.3 - 2.0)/680 = 1.9 mA when PGOODALL is released. Low state: 3.3/680 = 4.9 mA sunk at VOL <= 0.2 V, so the LED is off.
- LD4: (3.7 - 2.0 - 0.065)/1.0k = 1.6 mA typical (1.3 mA at VU 3.4 V, 2.6 mA at 4.7 V). It is drawn from VU, so it is inside the CLPROG-limited budget.
- Asar ENALL: VEN = VU x 4.5M/(4.5M + 100k) = 0.978 x VU, i.e. 2.9-4.6 V > VIH 1.2 V. With EN held low, R26 draws VU/100k = 30-47 uA.
- Thermal: IC loss about 0.4 W typical, about 0.6 W maximum (including (VOUT-BAT) x ICHG = 0.3 x 0.248 = 75 mW). Rise = 0.6 x 37 C/W = 22 C (p2), far from the 110 C thermal regulation point.

## Datasheet ambiguities and choices

- Resolved, Design B error: B put the buck-boost inductor on L8 and the PowerPath inductor on L1. Old L1 was U5's (VCC3V3 buck-boost) inductor, so the same-role rule keeps L1 = buck-boost; the PowerPath inductor is the new L8 (Design A).
- Resolved, Design A error: A used RFB = 104k. That is an E192 value, generally not stocked in 1 % thick film (RC0201/RC0402 1 % is E96/E24). The datasheet 105k (3.269 V) is used; 102k (3.341 V) is the E96 alternative.
- Resolved, CHRG LED rail: A used USB5V0, B used VU. VU is chosen. CHRG is 6 V abs max with no transient rating (p2), and p33 warns of about 10 V hot-plug ringing, which an idle LED would pass to CHRG. VU (<= 4.7 V, p3) is always >= 3.4 V when CHRG can sink, and its current is counted by CLPROG. R108 was recomputed to 1.0k.
- Resolved, LD3 meaning: B used LD3 as 'USB present' from USB5V0; A used it on PGOODALL. PGOODALL is chosen because LD5 already shows VCC3V3, and only PGOODALL shows that VCC1V0 and VCC1V8 are also up (p22). It is a shunt topology from VCC3V3, so it is dark with no drain when ENALL is low. The trade-off: there is no 'USB present' LED unless the battery is charging.
- Resolved, VIN1/VIN2 capacitors: B kept 10 uF 0805s (area cost); A used 1 uF 0402, which derates to about 0.5 uF at 4.5 V. 2.2 uF 0402 (GRM155R61A225KE95D) is chosen so about 1 uF effective remains (p28). VIN3 gets 10 uF 0603 (p28 asks for 2.2 uF).
- Resolved, VBUS capacitance: one 10 uF 16 V 0603 (A), not B's two 4.7 uF. One part, same nominal value as the p35 typical application. 0603 at 5 V gives only about 4-5 uF effective; p33 says a 16 V 1206 is more conservative. Measure hot-plug ringing against the 7 V transient abs max (p2/p33). The Fig 8 soft-connect PFET is not fitted (area).
- CLPROG over-use of 1x mode (USER DECISION PENDING): with DVCC grounded the limit is forced to 1x (p22). At the 3.01k placeholder the input is about 96 mA (0.45 W), so the board cannot run from USB alone and drains the battery even while plugged in. A deep-discharged cell may sit in trickle charge and show a false 6.1 Hz 'bad battery' (p19). The planned 560-620 ohm relies on hCLPROG(1x) = 224, which is characterised only at the 3.01k / about 100 mA point. It is probably fine (5x reaches the same currents) but not guaranteed. It also draws about 480 mA without USB enumeration.
- EC table p3 is garbled in text extraction. Reading used: IVBUSQ 7 mA (1x), 15 mA (5x/10x), 0.044 mA (suspend); hCLPROG 224/1133/2140/11.3. This is consistent with IBUSLIM 1x 87/95/100 mA at 3.01k. Table 3 (p21) mode order is also garbled; only '00 = 1x', stated explicitly on p22, is relied on.
- IPEAK_POWERPATH (p3) is given only as 2 A typical with no maximum. L8 Isat (2.5 A Element14 / 2.8 A another listing) is above the typical value; the abs max ISW of 2 A (p2) suggests the real limit is near 2 A. Accepted.
- Inductor ratings come from distributor listings that conflict: DFE252012F-2R2M Isat 3.3 vs 3.6 A (Itemp 2.3 A, DCR 82 mOhm max); DFE252012F-3R3M Isat 2.5 vs 2.8 A (Itemp 1.8 A, DCR 135 mOhm max); DFE201610E-2R2M Isat 1.9 vs 2.4 A (Itemp 1.7 A, DCR 140 mOhm max). The lower figures were used in every check. Confirm on Murata's own datasheets before ordering. The L1 Isat 3.3 A vs ILIMF3 max 3.0 A margin is only 10 %.
- The datasheet suggests 4.7 uH for the bucks (p27). 2.2 uH (the bottom of its 2.2-10 uH range) was chosen for area and DCR; ripple is 0.16-0.22 A p-p. DFE252012F-4R7M=P2 is a drop-in if less ripple is wanted. Also, abs max ISW1/ISW2 600 mA (p2) is lower than the ILIM1/2 max of 1.1 A; this datasheet inconsistency is noted but changes nothing here.
- SDA/SCL termination with DVCC grounded is not stated (p13, p20, p22). Both are tied to GND (the same net as DVCC) so they cannot float.
- PGOODALL behaviour while ENALL is low (no regulators enabled) is unspecified (p13/p22 say only 'all enabled regulators'). It does not matter here because the LD3 pull-up rail (VCC3V3) is 0 V then.
- There is no inter-rail delay or threshold spec for the ENALL sequence (p13); each rail soft-starts in about 0.5 ms (p24/p26) and G36 (p12) shows ordered start-up. Verify on the bench that VCC1V0 < VCC1V8 < VCC3V3 in order. Power-down order is not controlled: all three shut down together and SW1/SW2 are discharged through 10k (p6).
- Type III values (p30) assume COUT = 22 uF. VCC3V3 also carries about 167 uF of distributed decoupling, so the real LC pole lies at about 8-31 kHz. The zero-placement rule is still met, but phase margin was not simulated: run an LTspice model or a 0.1 -> 0.6 A load step at bring-up, and raise C3/C2 if it rings. The buck datasheet gives a minimum output cap (>= 4 uF effective, p28) but no maximum; VCC1V0 has about 165 uF and VCC1V8 about 72 uF.
- Battery-absent operation: p34 requires a 100 uF OSCON + 0 ohm from BAT to GND when the battery is disconnected. Not fitted (no area). Running from USB with no battery is outside datasheet guidance and impossible at 3.01k anyway. If it is wanted after the RCLPROG change, test BAT ripple, or add <= 22 uF ceramic in total on VBATT.
- GATE PFET not fitted (area, especially on Asar). The internal 0.18 ohm diode (1.6 A min limit) covers the worst-case 1.0 A battery load with a 0.18 V drop. Fit a Si2333-class PFET (source VOUT, drain BAT, gate GATE; p17) only if low-battery brown-outs show up. GATE floats per p13.
- LDO3V3 is disabled by tying it to VOUT (p12/p17), so no 1 uF cap is fitted. The task asked for an LDO3V3 cap: 1 uF is required only if the LDO is used.
- NTC grounded means no temperature-qualified charging. Only the pack protection and the 110 C die thermal regulation remain (p4/p20).
- The ENALL internal pull-down is 4.5 M in the EC (p4) but 5.5 M in Pin Functions (p13). This is irrelevant with a 100k pull-up or a hard tie.
- Asar: ENALL abs max is min(6 V, MAX(VBUS,VOUT,BAT)+0.3 V) (p2). A Feather host actively driving EN high while this board has neither VBUS nor battery would exceed it. Normal Feather practice is to switch EN to GND only. If active drive is expected, add a 10k series resistor between X2-18 and ENALL (not included). EN low leaves the PowerPath and charger running: about 30 uA IQ plus 47 uA through R26.
- With I2C disabled the bucks are fixed in pulse-skip mode and the buck-boost in PWM (p22). There is no Burst Mode, so no-load IQ is about 225-400 uA per regulator (p5/p6). Acceptable for an FPGA board.
- Fab B X2-22 still exposes VU (now the PowerPath VOUT). Treat it as an output only; back-driving it would fight the PowerPath and ideal diode.
- LED pin numbering: parts list pin1/pin2 for LD3/LD4 are given by function (anode/cathode). Check them against the LTST-C191 footprint's cathode mark when re-wiring LD3 (polarity reversed relative to the old bq PGOOD circuit, whose cathode went to the pin).

## 2026-11-10: R116 = 104k (VCC3V3 3.29 V) and operating limits from an outside review

R116 (FB3 divider bottom, DC only) 105k -> 104k: VCC3V3 = 0.8 V x (1 + 324k/104k) = 3.29 V (was 3.27 V). R115 stays at
324k because it is also the Type III R1 that sets the buck-boost compensation. 104k is an E192 value, so the part is a
0.1 % thin film (Panasonic ERA-1AEB1043C, 0201) instead of the 1 % E96 RC0201 range. (An outside review suggested
102k "for 3.30 V"; 102k gives 3.34 V.)

Operating limits to document for users:
- USB alone (~465 mA at 5 V, about 2 W after conversion) runs light FPGA designs (about 1.5 W board total). A heavy
  design (VCCINT about 1 A, VCC3V3 worst case) needs more than 3.5 W: it needs the battery connected, which makes up
  the difference through the ideal diode.
- On battery at about 1.2 A the internal 180 mOhm ideal diode drops about 0.2 V and dissipates about 0.26 W. The
  external PFET on GATE (left open) is the fix if heavy battery-only use ever matters; no space is reserved for it.
- Start-up order 1V0 -> 1V8 -> 3V3 relies on U7's 100 us soft-start and Buck1's sequencing slot (a recommendation in
  DS181, not a requirement). Power-down: Buck2 and the buck-boost both run from VOUT and stop together at UVLO; scope
  the 3.3 V vs 1.8 V decay at bring-up (DS181 T_VCCO2VCCAUX).
- Inductor saturation margins all pass: L8 2.5 A (needs ~1.5), L1/L2/L9 3.3 A (L1 needs ~2, switch limit 3 A max),
  L3 >= 1.8 A (~1.2 A peak at 1 A).
