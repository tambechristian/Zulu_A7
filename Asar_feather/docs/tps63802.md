# U5: SC189Z buck -> TPS63802 buck-boost (2026-11-09)

Why: with a LiPo the input falls from 4.2 V to about 3.0 V, below the 3.3 V rail, which a buck cannot hold. The TI
TPS63802 (buck-boost, 1.3-5.5 V in) keeps VCC3V3 regulated across the whole discharge. Same change on Zulu A7 Fab B
(see Zulu_A7_Fab_B/docs/tps63802.md).

## Schematic (sheet 1)

Datasheet SLVSEU9D, Figure 10-1 / Table 10-5.

| U5 pin | Net | Notes |
|---|---|---|
| 10 VIN | VU | C147 10 uF input cap |
| 1 EN | EN | unchanged (Feather EN pin, R26 pull-up) |
| 2 MODE | GND | power-save mode |
| 3 AGND, 8 GND | GND | |
| 9 L1 / 7 L2 | NetL1_1 / NetL1_2 | L1 = Murata DFE252010F-R47M=P2, 0.47 uH, Isat 6 A, same 2520 footprint |
| 6 VOUT | VCC3V3 | C80 22 uF output cap |
| 4 FB | NetR109_1 | R109 511k to VCC3V3, R110 91k to GND: 0.5 V x (1 + 511/91) = 3.31 V |
| 5 PG | - | open drain, unused, No-ERC cross |
