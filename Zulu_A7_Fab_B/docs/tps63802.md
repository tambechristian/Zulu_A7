# U5: SC189Z buck -> TPS63802 buck-boost (2026-11-09)

Why: with a LiPo the input falls from 4.2 V to about 3.0 V, below the 3.3 V rail, which a buck cannot hold. The TI
TPS63802 (buck-boost, 1.3-5.5 V in) keeps VCC3V3 regulated across the whole discharge. Same change on Asar Feather
(Asar_feather/docs/tps63802.md has the schematic table; the circuit is identical except EN, tied to VU here).

## Schematic (sheet 1)

U5 TPS63802DLAR; MODE = GND (power save); AGND/GND to GND; L1 = DFE252010F-R47M=P2 0.47 uH (same 2520 footprint);
C147 10 uF in, C80 22 uF out (kept); FB divider R109 511k / R110 91k = 3.31 V; PG unused (No-ERC cross). U6/U7 blocks
moved down 40 units to make room. ERC 0 errors, no new warnings.
